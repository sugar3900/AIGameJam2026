# HA-ART-09 — hall-end landscape

Original generated river landscape and multiview frame concept for the west-end focal point in the A+ hall. The frame has a mitered dark walnut base, raised rim, muted brass inner fillet, separate picture surface and rear backing/mount. The visual reference depicts a hanging wire; this version instead has a small simple mounting plate. It is static art, with optional future inspection interaction.

- Closed dimensions: **0.900 m wide × 0.035 m deep × 0.650 m high**. Blender space: X width, Z up, front faces −Y, rear is at Y=0; object geometry sits from Z=0 to Z=0.65. The FBX was exported −Y forward, Z up, with unit scale. Confirm Unreal's import transform and combine-mesh pivot before placement.
- `textures/river_landscape.png` is the original generated full-bleed painting. It uses one coherent UV island on `Painted landscape` with rough opaque material, no extra glass. `textures/walnut_painterly.png` is the independently generated wood. Texture images are packed in the `.blend` and also stored externally. The generated image is slightly wider in aspect than the modeled opening and is mildly compressed horizontally.
- Blender scene is editable in `model/HA-ART-09.blend`; `model/build.py` regenerates the source/FBX and previews. `model/validate.py` imports the FBX fresh and verifies geometry, UVs, finite values, nonzero triangle area and dimensions. The last reimport reported six meshes and 122 triangles, bounding box 0.900 × 0.035 × 0.650 m.
- Import `model/HA-ART-09.fbx` at the standard Blender FBX scale. Reconnect the two image textures to their named materials; set them to sRGB. Use a rough opaque surface for the picture so it reads under hall lighting; use muted metallic brass and rough walnut for trim. Blender nodes and packed paths are not a promise of automatic Unreal material reconstruction.
- Intended placement: hallway west focal wall above the shallow cabinet. Keep back face flush to the wall, preserve the long entry-to-art sightline, and check camera framing and readability. Use no collision or a simple thin box only if gameplay needs it; don't add detailed picture collision. No Unreal import, lighting, collision, runtime interaction, or in-room appearance has been verified.
