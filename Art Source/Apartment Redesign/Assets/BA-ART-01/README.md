# BA-ART-01 — bathroom fern print

Provisional candidate for `P-ART-BA-PRINT` in the A+ bathroom. The original painterly fern illustration is `textures/fern_print.png`; the generated period-frame front/back/side/perspective design sheet is `references/frame-multiview.png`. The sheet guides the frame style, while the separate illustration is the selected artwork. It is distinct from the bedroom rose print.

`model/BA-ART-01.blend` is editable source and `model/BA-ART-01.fbx` is a six-mesh static assembly with the pale ivory mitered frame, brass inner fillet, botanical art, backing and mounting plate. Frame geometry is adapted from the project's `BR-ART-FLORAL-01` build and proportioned to **0.300 m wide × 0.035 m deep × 0.360 m high**. Blender coordinates use metres, X across the width, +Z up, front toward −Y; bottom centre is at the origin and rear mounting surface is at Y=0. FBX is exported −Y forward / +Z up. Confirm Unreal axis conversion, pivot and frame orientation on import; place the back flush with the intended wall rather than using the studio preview wall, which is not exported. It is a static picture; any inspect interaction would be implemented in game.

`textures/ivory_frame.png` is copied from `ARC-WINDOW-01` for consistent period wood trim. Reconnect the ivory and botanical image textures in Unreal; Blender material nodes do not transfer as the finished shader. Recreate a rough painted-wood material and muted brass material for the fillet; the artwork is a matte image surface. The frame has restrained texture-based wear; no physical flaking is modeled. The botanical texture and all reference imagery are generated visual art, not a measured blueprint.

Rebuild with `/Applications/Blender.app/Contents/MacOS/Blender -b --python 'Art Source/Apartment Redesign/Assets/BA-ART-01/model/build.py'` from repository root. Reimport validation uses `model/validate.py`; `model/validation.txt` reports six meshes, 122 triangles, finite geometry/UVs, no zero-area geometry triangles and the target 0.300 × 0.035 × 0.360 m bounds. The `previews/` renders use studio lighting only. Unreal import, in-room appearance, material mapping, collision and placement have not been tested.

Image-generation prompts: (1) a painterly vintage maidenhair-fern botanical on warm ivory paper, no text or frame, matching the environment reference; (2) a multiview 30 × 36 cm pale period frame with fern print and aged brass inner fillet. Both were generated with the built-in image tool; the selected source illustration is included in this folder.
