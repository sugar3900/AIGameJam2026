# 2026-11-07

## Goals today
- [x] Docs vault

## Done
- Project `ICanFixHim` (UE 5.8, C++). Gameplay, UI and input are all code; level and materials generated by Python scripts so everything is diffable.
- Apartment "12 Heartbreak Lane": living room, kitchen, bedroom, bathroom; pastel per room; furniture from primitives.
- Rosie (third person), reticle → painted-nail pointer, hover outlines, sparkles, toggles.
- Four hunks with full 4-visit arcs, puns, topics, interconnections, 4 endings each (≈4,500 words of dialogue).
- Visual-novel dialogue box with live portrait, meters, hearts, fade-to-black.
- Intro card with silhouette, ending cards, floor plan fast travel, title/pause/options/credits, JSON saves.
- Automated playtests drive PIE via console commands and screenshots.

## Problems / blockers
- Editor launched from a shell hung on a macOS privacy prompt (Home Screen scanning ~/Documents). Fixed by launching via `open -a`.
- UBT used hot-reload dylib names while another UE editor was open, so the editor loaded stale code. Fixed with `-NoHotReload`.
- `PreSkinnedPosition` is vertex-shader only. Needed a VertexInterpolator in `M_Character`.
- Python remote execution on macOS needs multicast bound to 0.0.0.0.

## Decisions
- Single map; title screen is a live view of the apartment.
- Inverted-hull outlines instead of post-process stencil.
- Hunks share the UE mannequin; identity comes from outfit material + primitive props + colour.
