# Tech Overview

## Stack
- **Engine:** Unreal Engine 5.8, C++ (no Blueprints needed for gameplay or UI)
- **Source control:** Git + **Git LFS** for `.uasset` / `.umap` / art / audio (see `.gitattributes`; Unreal assets are `lockable`)
- **Target:** macOS (Metal SM6) and Windows (DX12 SM6)
- **Rendering:** Lumen GI + reflections, virtual shadow maps, TSR, auto-exposure clamped by a post-process volume
- **AI tooling:** Unreal MCP server (`localhost:8001`, `.mcp.json`) + Python remote execution (`Tools/run_in_editor.py`)

## Project structure
```
Source/ICanFixHim/
  Core/      UFixHimSettings (all asset refs, in DefaultGame.ini), UFixHimSaveSubsystem (JSON saves/options),
             AFixHimGameMode, FixHim::Assets (runtime primitive/material helpers)
  Dialogue/  UFixHimDialogueSubsystem (loads JSON, runs conversations), FixHim::Condition (expression evaluator)
  Player/    AFixHimCharacter (Rosie), AFixHimPlayerController (state machine, input, menus, encounters)
  World/     AFixHimInteractable (sparkle, outline, toggles), AFixHimMalady (fixture + hunk + broken fx),
             AFixHimHunk (the man: rigged model + idle, or painted mannequin with props; portrait capture, pop-in), AFixHimRoom (volume + floor-plan rect)
  UI/        UFixHimWidget base + code-built UMG screens (title, HUD, dialogue, floor plan, intro/ending cards, menus)
Content/ICanFixHim/
  Data/Dialogue/*.json   story (staged as non-UFS so it can be edited after packaging)
  Maps/L_Apartment       generated level
  Materials/             generated: M_FlatColor, M_Character, M_Translucent, M_Shine, M_UI_Portrait, Palette/MI_*
  UI/                    T_Pointer, T_Heart (from Tools/Art/*.svg)
Tools/                   editor/build scripts (see README)
```

## Key decisions
| Decision | Why |
|---|---|
| **UI built in C++** (UMG `WidgetTree` in `BuildUI()`) | Diffable, reviewable, AI-editable; no binary widget blueprints to merge. |
| **Level & materials generated by Python** | Reproducible; the apartment is a script, not a hand-placed `.umap` nobody can diff. |
| **Dialogue as JSON + tiny condition language** | Twine-like authoring without a Twine dependency; easy for humans and LLMs to write; linted by `validate_dialogue.py`. |
| **Input actions built in code** | The whole control scheme is in `BuildInput()`; no asset juggling. |
| **Soft refs in `UFixHimSettings`** | No hard-coded content paths in C++; designers can swap assets in Project Settings. |
| **Single map** | Title screen is a live view of the apartment; "Main Menu" just reloads the map. |
| **Outfits via material, not new meshes** | `M_Character` paints shirt/pants/skin/shoes by reference-pose height (`PreSkinnedPosition`), so one mannequin gives every hunk a distinct look. |
| **Inverted-hull hover outline** | Reverse-culled, slightly enlarged copy of each primitive. Simple and robust, no post-process stencil setup. |
| **Portraits from scene captures** | Live, animated portrait of whoever you're talking to; same capture drives the intro-card silhouette (alpha from SceneColorHDR). |

## Game states (AFixHimPlayerController)
`Title → Playing ⇄ (Encounter → Dialogue) → Ending → Playing`, plus `FloorPlan`, `Paused`, `Traveling`.

## Save format
`Saved/SaveGames/ICanFixHim_Save.json` with per-hunk romance/friendship/friction, visits, met, fixed, ending and seen nodes, plus global flags and the player transform. Options are saved separately in `ICanFixHim_Options.json`.

## Build & run
- Editor: `Build.sh ICanFixHimEditor Mac Development -Project=... -WaitMutex -NoHotReload` (`-NoHotReload` matters if another UE editor is open; otherwise UBT writes numbered dylibs the editor won't load).
- Regenerate content: `python3 Tools/run_in_editor.py Tools/Editor/create_assets.py`, then `... build_apartment.py`.
- Automated playtest: in PIE, `FixHimScript "FixHimNewGame;wait 2;FixHimTalk lukey;wait 5;FixHimAuto 2;FixHimShot test"`.

## Known gotchas
- On macOS, launch the editor with `open -a UnrealEditor.app ...` (not from a shell), or the Home Screen's scan of `~/Documents/Unreal Projects` can hang on a privacy prompt.
- Python remote execution must bind multicast to `0.0.0.0` on macOS (already in `DefaultEngine.ini`).
- Killing the editor can leave `CrashReportClient` holding the MCP port (8001). Kill it too.
- `Esc` ends a PIE session by default. Use `P` to pause in PIE, or play in Standalone.
