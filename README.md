# I Can Fix Him

*A home-renovation dating sim. AI Game Jam 2026.*

Rosie just bought a decrepit house. Every broken thing in it, from the leaky sink to the black mold to the faulty wiring to the 1957 pink tile, turns out to be a hot, trapped man. Fix the house, get to know the men, and decide whether each one becomes a romance, a friend, or bad blood.

**Engine:** Unreal Engine 5.8 (C++), macOS / Windows

## Getting started

1. **Install Git LFS** before cloning (all `.uasset` / `.umap` files are in LFS):
   ```bash
   git lfs install
   git clone https://github.com/sugar3900/AIGameJam2026.git
   ```
2. **Build the editor target** (or open `ICanFixHim.uproject` and let it compile):
   ```bash
   # macOS
   "/Users/Shared/Epic Games/UE_5.8/Engine/Build/BatchFiles/Mac/Build.sh" ICanFixHimEditor Mac Development -Project="$PWD/ICanFixHim.uproject" -WaitMutex
   ```
   On Windows, right-click the `.uproject` and choose *Generate Visual Studio project files*, then build `ICanFixHimEditor`.
3. Open `ICanFixHim.uproject`. The startup map is `/Game/ICanFixHim/Maps/L_Apartment`. Press **Play**.

### Controls
| Action | Keys |
|---|---|
| Move / look | WASD + mouse (or gamepad sticks) |
| Interact / advance dialogue | Left click, E, Space, Enter |
| Pick a dialogue choice | Click it, or 1-5 |
| Ask about a highlighted word | Click the pink word |
| Floor plan (fast travel) | M or Tab |
| Pause | Esc or P (in PIE, Shift+Esc may be needed since Esc stops PIE) |

## Working on the game

- **Writing dialogue:** see [`docs/04 Tech/Dialogue Format.md`](docs/04%20Tech/Dialogue%20Format.md). Edit the JSON, run `python3 Tools/validate_dialogue.py`, then type `FixHim.ReloadDialogue` in the game console.
- **Changing the apartment:** edit `Tools/Editor/build_apartment.py`, then run `python3 Tools/run_in_editor.py Tools/Editor/build_apartment.py` with the editor open. The level is rebuilt from scratch, so don't hand-edit `L_Apartment`; change the script instead.
- **Tuning / asset refs:** *Project Settings > Game > I Can Fix Him*.
- **AI tooling:** the editor runs the Unreal MCP server on `localhost:8001` (see `.mcp.json`), and Python remote execution is enabled for `Tools/run_in_editor.py`.

### Debug console commands (in game)
`FixHimNewGame`, `FixHimTalk <id>`, `FixHimAuto 1,2,1` (auto-play a conversation with those choices), `FixHimChoose <n>`, `FixHimTopic <word>`, `FixHimMap`, `FixHimGoto <room>`, `FixHimDump`, `FixHimShot <name>`, `FixHimScript "cmd;wait 1;cmd"`, `FixHim.ReloadDialogue`.

Saves live in `Saved/SaveGames/ICanFixHim_Save.json` (human-readable).
