# I Can Fix Him

*A home-renovation dating sim. AI Game Jam 2026.*

Rosie just bought a decrepit house. Every broken thing in it, from the leaky sink to the black mold to the faulty wiring to the 1957 pink tile, turns out to be a hot, trapped man. Fix the house, get to know the men, and decide whether each one becomes a romance, a friend, or bad blood.

**Engine:** Unreal Engine 5.8 (C++), macOS / Windows

## Getting started

1. **Install Git LFS** before cloning (all `.uasset` / `.umap` files are in LFS):
   ```bash
   git lfs install
   git clone https://github.com/sugar3900/AIGameJam2026.git
   ```
2. **Build the editor target** (or open `ICanFixHim.uproject` and let it compile):
   ```bash
   # macOS
   "/Users/Shared/Epic Games/UE_5.8/Engine/Build/BatchFiles/Mac/Build.sh" ICanFixHimEditor Mac Development -Project="$PWD/ICanFixHim.uproject" -WaitMutex
   ```
   On Windows, right-click the `.uproject` and choose *Generate Visual Studio project files*, then build `ICanFixHimEditor`.
3. Open `ICanFixHim.uproject`. The startup and game default map is the revision 02 apartment, `/Game/ICanFixHim/Maps/L_Apartment_Rev02` (gameplay actors live in its streamed sublevel `L_Apartment_Rev02_Gameplay`). Press **Play**. The earlier A+ redesign (`L_Apartment_Redesign_Blockout`) and the original `L_Apartment` are still in the project and can be opened directly; non-default maps keep separate save files.

### Controls
| Action | Keys |
|---|---|
| Move / look | WASD + mouse (or gamepad sticks) |
| Interact / advance dialogue | Left click, E, Space, Enter |
| Pick a dialogue choice | Click it, or 1-5 |
| Ask about a highlighted word | Click the pink word |
| Floor plan (fast travel) | M or Tab |
| Pause | Esc or P (in PIE, Shift+Esc may be needed since Esc stops PIE) |

## Working on the game

- **Story Writer:** a Twine-style graph editor + previewer for all the dialogue: `dotnet run --project Tools/StoryWriter` (see [`Tools/StoryWriter/README.md`](Tools/StoryWriter/README.md)).
- **Writing dialogue:** see [`docs/04 Tech/Dialogue Format.md`](docs/04%20Tech/Dialogue%20Format.md). Edit the JSON, run `python3 Tools/validate_dialogue.py`, then type `FixHim.ReloadDialogue` in the game console.
- **Changing the apartment:** edit `Tools/Editor/build_apartment.py`, then run `python3 Tools/run_in_editor.py Tools/Editor/build_apartment.py` with the editor open. The level is rebuilt from scratch, so don't hand-edit `L_Apartment`; change the script instead.
- **Rebuilding environment art:** With this project open in the editor, run `Tools/Editor/create_painterly_material.py`, `Tools/Editor/import_environment_textures.py`, `Tools/Editor/import_window_view.py`, and `Tools/Editor/import_environment.py`, in that order, then rebuild `Tools/Editor/build_apartment.py`. Source models and generators are under `Art Source/Environment Models` and `Tools/Art/Environment`. Run `Tools/Editor/validate_environment.py` to check the saved level's interaction traces, doorway clearances, and repair-damage attachments; run `Tools/Editor/validate_environment_pie.py` during PIE to check hunk placement, dialogue sightlines, and moving prop materials. `Tools/run_in_editor.py` selects only an editor open on this exact checkout.
- **Character models:** source art lives in `Art Source/Character Art/<Name>/` (Tripo exports). To (re)import, run `/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python Tools/Art/prepare_characters.py`, then `python3 Tools/run_in_editor.py Tools/Editor/import_characters.py`. Add a new character to the `CHARACTERS` table in both scripts, then point a hunk at it with `look.mesh` / `look.idle` in its dialogue JSON.
- **Dialogue portraits:** `python3 Tools/Art/Portraits/render_portraits.py` (needs `pip install pillow numpy opencv-python-headless`) writes `Art Source/Portraits/T_Portrait_<Name>.png` from each hunk's front turnaround (crop and colours are in its table); then `python3 Tools/run_in_editor.py Tools/Editor/import_portraits.py`. A hunk uses his with `look.portrait` in his dialogue JSON; the player's is `PlayerPortraitTexture` in `Config/DefaultGame.ini`.
- **Tuning / asset refs:** *Project Settings > Game > I Can Fix Him*.
- **AI tooling:** the editor runs the Unreal MCP server on `localhost:8001` (see `.mcp.json`), and Python remote execution is enabled for `Tools/run_in_editor.py`.

### Debug console commands (in game)
`FixHimNewGame`, `FixHimTalk <id>`, `FixHimAuto 1,2,1` (auto-play a conversation with those choices; also dismisses the first-meeting card), `FixHimChoose <n>`, `FixHimTopic <word>`, `FixHimMap`, `FixHimGoto <room>`, `FixHimDump`, `FixHimShot <name>`, `FixHimScript "cmd;wait 1;cmd"` (waits use game time, so they stall while paused), `FixHimClickAt <x> <y>` (click the topmost screen at a 0..1 viewport position: sliders, buttons, click-outside-to-close), `FixHimReturnToTitle`, `FixHim.ReloadDialogue`, `Sfx.Test <Cue>`, `Music.Play <Track>`, `Music.Status`.

Saves live in `Saved/SaveGames/ICanFixHim_Save.json` (human-readable).
